## 🤖 Task 4 - Basic Chatbot
A rule-based chatbot that interacts with users using predefined responses.

✨ Features:
- Responds to greetings and basic queries
- Loop-based conversation system
- Exit command using "bye"

🧠 Concepts Used: if-elif, loops, input/output

---

## 🎮 Task 1 - Hangman Game
A text-based word guessing game where the user guesses letters to complete a hidden word.

✨ Features:
- Random word selection from 5 predefined words
- Limited wrong attempts (6 chances)
- Win/Loss conditions with feedback

🧠 Concepts Used: random, while loop, strings, lists, conditionals

---

## 📈 Task 2 - Stock Portfolio Tracker
A program that calculates total investment based on user-selected stocks and quantities.

✨ Features:
- Predefined stock price list (AAPL, TSLA, GOOGL, AMZN, MSFT)
- User input for portfolio creation
- Total investment calculation
- Save portfolio to a text file

🧠 Concepts Used: dictionary, file handling, loops, arithmetic operations
